# docs/ — материалы по лабораторным работам

Сюда складываем отчётность по каждой ЛР (скриншоты + краткий разбор). План и требования — в корневом `README.md`, разделы 3 и 5.

| Файл | ЛР | Что внутри |
|---|---|---|
| `ЛР3_Формы.md` | ЛР3 | 3 формы элемента/документа + 2 формы списка: скриншоты «до/после», список изменённых свойств, назначение собственных реквизитов формы |
| `ЛР4_Обработчики.md` | ЛР4 | таблица «№ → вид события → обработчик → форма/элемент → код», скриншоты срабатывания |
| `ЛР5_Модули_объектов.md` | ЛР5 | листинги 6 модулей объектов + движения регистров, как проверить заполненность всех 4 регистров |
| `ЛР6_Загрузка_Excel.md` | ЛР6 | как собрать внешнюю обработку `.epf` (в методичке только скриншоты), скрин «до/после» загрузки, отчёт о загрузке |
| `ЛР7_Отчеты_СКД.md` | ЛР7 | тексты запросов, карта настроек (параметры, вычисляемые поля, ресурсы, отбор/сортировка/условное оформление), скриншоты результата |

Исходники ЛР1 и ЛР2 лежат в корне: `ЛР1_Проектирование_структуры.md`, `ЛР2_Создание_объектов_пошагово.md`.
